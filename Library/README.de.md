# XpressNet-Bibliothek
Die Bibliothek hat in allen Codebasen dieselben Methoden, Events und Attribute. Pro Codebasis:

| Codebasis | Quellcode | Kompiliert | Installation |
|---|---|---|---|
| macOS (Objective-C, Xcode) | [src/macOS](src/macOS) | - (der Quellcode wird der Anwendung hinzugefügt) | [Anleitung](src/macOS/Install/Install-Library.md) |
| Qt (C++, Qt 6, CMake; Linux und Windows) | [src/Qt](src/Qt) | - (wird zusammen mit der Anwendung gebaut) | [Anleitung](src/Qt/Install/Install-Library.md) |
| .NET (C#, .NET Framework 4.7.2) | [src/DotNet](src/DotNet) | [compiled/DotNet](compiled/DotNet) | [Anleitung](src/DotNet/Install/Install-Library.md) |
| VB6 (COM-DLL) | [src/VB6](src/VB6) | [compiled/VB6](compiled/VB6) | [Anleitung](src/VB6/Install/Install-Library.md) |

Die Installationsanleitungen gibt es auf Englisch und Niederländisch.

Die [Dokumentation](Documentation) gilt für alle Codebasen:
- [Reference manual](Documentation/Reference/Reference.md) (Englisch): alle Methoden, Events und Attribute, mit den XpressNet-Nachrichten und den Kapiteln der Spezifikationen.
- [Commands](Documentation/Commands): PDF-Dateien mit den implementierten Befehlen und wie gut sie getestet wurden.
- [HowToUse](Documentation/HowToUse/Handleiding.md): Benutzerhandbuch (nur Niederländisch) für VB.NET und VB6.

Die [Beispiele](../Examples/README.de.md) zeigen, wie die Bibliothek verwendet wird.
