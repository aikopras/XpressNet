# XpressNet library
The library has the same methods, events and attributes in all code bases. Per code base:

| Code base | Source | Compiled | Installation |
|---|---|---|---|
| macOS (Objective-C, Xcode) | [src/macOS](src/macOS) | - (the source is added to the application) | [manual](src/macOS/Install/Install-Library.md) |
| Qt (C++, Qt 6, CMake; Linux and Windows) | [src/Qt](src/Qt) | - (built together with the application) | [manual](src/Qt/Install/Install-Library.md) |
| .NET (C#, .NET Framework 4.7.2) | [src/DotNet](src/DotNet) | [compiled/DotNet](compiled/DotNet) | [manual](src/DotNet/Install/Install-Library.md) |
| VB6 (COM DLL) | [src/VB6](src/VB6) | [compiled/VB6](compiled/VB6) | [manual](src/VB6/Install/Install-Library.md) |

The [Documentation](Documentation) applies to all code bases:
- [Reference manual](Documentation/Reference/Reference.md): all methods, events and attributes, with the XpressNet messages and the chapters in the specifications.
- [Commands](Documentation/Commands): PDF files with the implemented commands, and how well they were tested.
- [HowToUse](Documentation/HowToUse/Handleiding.md): user manual (Dutch only) for VB.NET and VB6.

The [examples](../Examples/README.md) show how the library is used.
